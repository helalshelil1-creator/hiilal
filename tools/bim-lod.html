دليل مستويات LOD في BIM

مستويات تطوير النموذج من 100 إلى 500 — التعريف والاستخدام والمخرجات

مصطلحات BIM الأساسية

BIM — نمذجة معلومات البناء Building Information Modeling

منهجية إنشاء وإدارة نموذج رقمي للمبنى يجمع الشكل الهندسي مع البيانات (المقاسات، المواد، الأحمال، التواريخ، التكلفة) في مكان واحد يستخدمه كل الأطراف.

BEP — خطة تنفيذ BIM BIM Execution Plan

المستند اللي بيحدد قبل بدء المشروع: مين بيمودّل إيه، ولأي مستوى LOD، وبأي برنامج وإصدار، وقواعد التسمية، ومواعيد التسليم وتبادل النماذج بين التخصصات.

CDE — بيئة البيانات المشتركة Common Data Environment

المكان الموحّد لتخزين وتبادل ملفات المشروع (نماذج، لوحات، مستندات) بحالة واضحة لكل ملف: قيد العمل WIP، مشترك Shared، منشور Published، أرشيف. أمثلة: Autodesk Docs / BIM 360، Trimble Connect.

IFC Industry Foundation Classes

صيغة ملف مفتوحة (ISO 16739) لتبادل نماذج BIM بين البرامج المختلفة من غير فقدان البيانات — زي الـ PDF لكن لنماذج المباني.

Clash Detection — كشف التعارضات

فحص آلي للنموذج المدمج (Navisworks مثلًا) لاكتشاف تقاطع العناصر قبل التنفيذ: دكت ضد كمرة، مواسير ضد كابل تراي. النوع Hard clash تلامس فعلي، وSoft clash اختراق مسافات التشغيل والصيانة.

COBie Construction Operations Building information exchange

صيغة جداول (Excel) لبيانات التشغيل والصيانة: المعدات، الضمانات، قطع الغيار، أدلة التشغيل — بتتسلم مع LOD 500 لإدارة المرافق.

4D و 5D

4D = النموذج + الزمن (ربط العناصر بالجدول الزمني ومحاكاة تسلسل التنفيذ). 5D = النموذج + التكلفة (حصر كميات حي مرتبط بالأسعار).

LOD و LOIN Level of Information Need

ISO 19650 استبدلت فكرة "LOD واحد لكل المشروع" بمصطلح LOIN: تحديد مستوى الهندسة ومستوى المعلومات المطلوب لكل عنصر وكل مرحلة على حدة — لتجنب الموديلنج الزائد عن الحاجة.

المراجع: BIMForum — Level of Development (LOD) Specification · AIA G202-2013 Project BIM Protocol · ISO 19650.
