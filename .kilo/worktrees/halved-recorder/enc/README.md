# 🏗️ مكتب المهندس هلال شليل

منصة هندسية متكاملة لمهندس الكهرباء والـ MEP.

## ✨ المميزات

- 🧰 **أدوات هندسية** — حاسبات، Checklists، جداول
- 🧮 **حاسبات متقدمة** — كابل، قاطع، هبوط جهد، إضاءة
- 📚 **موسوعة هندسية** — 8 تصنيفات + 30+ موضوع
- 📘 **أكواد ومعايير** — IEC، NFPA، BS، IEEE، ECP
- 📦 **منتجات ومعدات** — قاعدة بيانات كاملة
- 🖥️ **دليل AutoCAD & Revit** — كل الأوامر والاختصارات
- 🎥 **فيديوهات YouTube** — إدارة من لوحة التحكم
- 🔐 **لوحة تحكم** — إدارة كامل المحتوى
- 📱 **PWA** — يعمل offline + يثبت على الجوال
- 🌙 **Dark Mode** — وضع ليلي كامل
- 🌐 **عربي/إنجليزي** — تبديل اللغة
- 🎨 **ألوان قابلة للتخصيص** — Cyan / Purple

## 🚀 التقنيات

- HTML5, CSS3 (CSS Variables), Vanilla JavaScript
- Service Worker + PWA
- LocalStorage للبيانات
- YouTube Embed API
- Pollinations AI للبوت
